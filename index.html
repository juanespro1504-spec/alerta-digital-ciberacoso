¿Qué es el ciberacoso?

Es el uso de medios digitales para hostigar, humillar, amenazar o hacer daño de forma intencional a otra persona.

  • Insultos repetidos o humillaciones.
  • Amenazas o mensajes intimidantes.
  • Difusión de rumores o contenido privado.
  • Persecución constante mediante cuentas o chats.

Si estás viviendo una situación así

No tienes que resolverlo a solas.

  • No respondas con más agresiones.
  • Guarda evidencias y bloquea la cuenta si es seguro hacerlo.
  • Cuéntaselo a alguien de confianza.
  • Si hay amenazas creíbles o peligro inmediato, busca ayuda de las autoridades o servicios de emergencia de tu zona.

Pasos recomendados

  1. Aléjate un momento del chat si te sientes en riesgo.
  2. Conserva evidencias sin compartirlas.
  3. Bloquea y reporta el perfil.
  4. Busca apoyo de una persona de confianza y, si hay peligro, ayuda urgente local.

Sobre este prototipo

Este sitio representa una idea académica: usa una lista sencilla de términos de ejemplo para mostrar una alerta inicial. No utiliza inteligencia artificial ni puede confirmar que un mensaje sea ciberacoso.
